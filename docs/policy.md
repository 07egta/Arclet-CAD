# Arclet CAD 開発方針メモ（2026-11-02 時点）

## 目標
Rhino 級のオープンソース NURBS CAD をデスクトップ向けに作る。Melt3D とは独立。Rust が中心。見た目と操作は Rhino に近づける。

## 決めた方針
- **言語**: 基本は Rust。C++ のライブラリは、デスクトップ版で使ってよい（ブラウザ版で動かなくてよいと決定）。
- **コードの流用**: SolidCraft の一部は流用してよい。他の CAD（Rhino、Plasticity など）は作り方の「参考」まで。コードは写さない。
- **ライセンス**: GPL/LGPL/AGPL は使わない（OpenCASCADE は不可）。許可がはっきりしないもの（openNURBS）も、確認できるまで使わない。
- **正直さ**: できていないことを「できる」と書かない。互換性は COMPATIBILITY_MATRIX.md に段階つきで書く。
- **進め方**: 小さい AI の助手（Haiku）に分担。作業は別々の作業場所で行い、マージして検証してから push する。

## できたこと
- Rhino 風の画面（メニュー、ツールバー、コマンド行、ステータスバー、パネル、明るいテーマ）
- Rhino 風の短いコマンド名（147 個）
- レイヤー（表示・固定・色・割り当て）
- 3DM: 既存の cadmpeg 経由の読み込み。自前のヘッダー/目次読み取り（形はまだ読めない）
- C++ 試作: Clipper2（2D の広げる・重ねる）。標準ではオフ
- ビューポート 4 分割の下準備（見た目は変わらない）

## 作業中
- Manifold（立体の足し算・引き算, C++）の試作: 書き上がり、ビルド未確認
- レイヤーの仕上げ（削除、今のレイヤーに描く、色の反映）
- 本物の連続線コマンド（sketch.polyline）
