# Mission 34 — NURBS 曲面品質解析（実装範囲と限界）

この追加は **曲面の生成・修正を行わない**。 `crates/geom/src/surface_quality.rs` に解析用の read-only API を置き、既存の `NurbsSurface` の値・次数・ノット・有理制御点を読む。文書形式と Undo は変更しない。**Class A 認証ではない**。

## API / 計測

- `derivatives(surface,u,v)`: 同次座標の B-spline 基底の 0〜2 階の **解析微分** と有理商の微分。単位は位置 mm、一次 mm/parameter、二次 mm/parameter²。
- `curvature(surface,u,v)`: 第一・第二基本形式から符号付き主曲率 kmin/kmax (1/mm)、平均曲率 H (1/mm)、Gaussian K (1/mm²)、法線、最大絶対主曲率を返す。法線向きは `r_u × r_v`。退化した計量や不安定な微分はエラー。
- `sample_grid(surface,nu,nv)`: 各パラメータ方向 3〜129 点、最大 16,641 点。点ごとの曲率、隣接点の平均曲率差/弦長 (1/mm²)、法線角、実際の隣接点間隔を返す。これは微小うねりの**標本指標**であり、標本間のうねりを保証して検出するものではない。
- `measure_patch_join(a,edge_a,b,edge_b,reverse_second,stations,tolerances)`: 明示的に対応づけた曲面境界を 3〜257 標本で測る。最大 G0位置差(mm)、G1の法線の非平行角(deg)、G2の第二基本形式テンソル差(Frobeniusノルム、1/mm)を返す。G0→G1→G2の順で公差を満たした**標本次数**を返し、G3は「未評価」と明記する。

## 数学的前提

`E=r_u·r_u`, `F=r_u·r_v`, `G=r_v·r_v`, `e=n·r_{uu}`, `f=n·r_{uv}`, `g=n·r_{vv}`。

`K=(eg-f²)/(EG-F²)`, `H=(eG−2fF+gE)/(2(EG−F²))`, `k1,2=H±sqrt(max(0,H²−K))`。

境界テンソル差は最初の曲面の「辺接線と横断方向」の共通正規直交基底を使い、反対向きの法線について符号を調整する。**境界同士の幾何学的対応が既知**であることが前提。異なるパラメータ速度、異なるトリム曲線、最近点対応は自動推定しない。G2の標本一致は全域の保証ではない。

内部ノット位置で次数−重複度が2未満の箇所は2階微分を確定できないとして拒否。退化計量、ゼロ法線、非有限値は「曲率0」と見なさずエラーとする。

## 既存の UI / render との関係

`inspect.continuity` は B-rep エッジに沿う既存の法線角と法曲率ジャンプを表示し、`inspect.zebra` と `inspect.environment_map` は反射の**視覚診断**。 `inspect.curvature_map` は表示用の曲率尺度であり、上記のNURBS主曲率・K/Hと同一の計測ではない。

このPRでは新しいGPUオーバーレイ・Reflection Line・NURBS曲率コームUIは接続**していない**。既存の表示は残し、診断の数値結果とビューの美観を混同しない。新しいAPIを可視化する場合は、評価できなかった標本を別色で示し、法線方向・標本間隔・公差・計算方式・標本番号を併記する必要がある。

## テスト・数値基準

`crates/geom/src/surface_quality.rs` 内の解析解テスト:

| モデル | 期待値 |
|---|---|
| 平面 | k1=k2=H=K=0; 平面同士の G2 標本 |
| 正確な有理1/4円筒（R=4mm） | 絶対主曲率 0 と 0.25/mm、K=0、abs(H)=0.125/mm |
| 同じ円筒の隣接する2面 | 33標本で G2 |
| 0.01 の傾き違いの接面 | 約0.573度、G0のみ |
| 平面→二次曲面 | G1、曲率テンソル差 2/mm |
| 0.02mm の隙間 | G0不合格 |
| 退化した点・C1ノットの2階微分 | エラー。G2と判定しない |
