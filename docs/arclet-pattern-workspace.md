# Arclet CAD のパターン編集

Arclet CAD のモデル画面で元の形を選び、配置を見ながら寸法を調整できるようにする。修正の入口には操作中の画面と保存済みのフィーチャー履歴を使う。

## 実装方針

- Arclet の既存の Rust／egui UI と、共有の SolidCraft コマンド、プレビュー、履歴を使う。既存のモデル形式にパターンが保存される。エンジンから直接呼ぶときは既存のコマンドに明示的な引数を渡す。
- モデル画面の **Pattern** から **Rectangular Pattern** または **Circular Pattern** を選ぶ。選択済みのボディを引き継ぎ、矩形にモデルの X／Y、円形に Z を初期値として入れる。モデル内の軸や方向に差し替えられる。
- 入力と適用前のプレビューに既存の編集パネルを使う。間隔の矢印が表示されたら、寸法入力と同じ値をドラッグで調整できる。適用後はタイムラインからフィーチャーを開き、元の参照や式を使って再編集する。
- Melt 3D の参考画面から、中央の形状を広く見せ、対象の選択、操作の入口、数値編集を見つけやすく分ける。Serpentine3D と Plasticity の操作例も参考にする。画面は Arclet のテーマトークン、既存のウィジェット、既存のアイコンに沿って設計する。

## 開発順序

1. 格子・円周の入口を揃え、選択、初回設定、プレビュー、適用、取り消し、保存と再編集を一通り動かす。
2. 既存の曲線沿い配列も同じ入口に置く。除外や千鳥は「1個」や「列」を結果から選び、配置を変えてもどの除外が残るかを確認できるようにする。
3. Grasshopper を参考に、配置、間引き、寸法の変化を既存のノード環境に接続する。許容する入力と更新範囲を決め、同じモデルを再計算できることを検証する。
4. Tスプラインは局所分割と曲面変換の幾何カーネルを独立して検証し、操作と保存の仕様を決めてから利用者向けのコマンドにつなぐ。

単純な形を100個配置する例で、操作からプレビュー表示までの95パーセンタイルを100 ms以内にすることを次段階の目標とする。初回メッシュ化と連続操作の時間をそれぞれ測る。

## 続きを担当する際の確認

- 入口は `apps/arclet/src/app.rs`、適用と再編集は `crates/ui-egui/src/dialogs.rs`、コマンドは `crates/engine/src/cmd/features.rs` にある。
- `cargo test --locked -p arclet` と `cargo test --locked -p solidcraft-ui-egui --lib pattern_arrow_tests` を実行する。コミット前の確認は `cargo xtask ci`。
- ボディを作って選択し、矩形と円形の両方を開く。プレビュー中のキャンセル、適用後の取り消し、保存して開き直した後の寸法編集を確認する。円形では既定軸を別の軸へ差し替える。
